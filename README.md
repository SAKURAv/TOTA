# Tota — واجهة عرض منتجات

موقع بصفحتين منفصلتين:
- **`index.html`** — الصفحة الرئيسية: هبوط بصري بحركات دخول، ماركي، ولمحة من المنتجات.
- **`products.html`** — صفحة الكتالوج الكاملة: فلاتر تصنيفات + بحث ذكي (Fuzzy Search) بالعربي.

## هيكل البيانات
```
products/
  <category-slug>/
    category.json          { "name": "اسم التصنيف", "order": 1 }
    <product-slug>/
      data.json             { name, price, oldPrice, currency, badge, description, specs:[{label,value}] }
      main.(svg|jpg|png|webp)
```
أضف فولدر منتج جديد بنفس الشكل، وشغّل البناء.

## التشغيل
```bash
npm run build     # يبني data/products.json من فولدر products/
npm run dev        # يراقب products/ ويعيد البناء تلقائيًا مع كل تعديل
npm run serve       # يشغل سيرفر محلي على http://localhost:5500
```
⚠️ افتح الموقع من خلال سيرفر محلي دايمًا — مش دبل كليك على index.html (fetch للـ JSON محتاج سيرفر).

## البحث الذكي
موجود في `assets/js/fuzzy-search.js`:
- بيوحّد أشكال الحروف المتشابهة (أ/إ/آ/ا، ة/ه، ي/ى، ؤ/ئ)
- بيتحمّل أخطاء إملائية بسيطة (Levenshtein distance)
- بيعمل تظليل (highlight) للجزء المطابق في نتيجة البحث

## التخصيص السريع (كله من ملف واحد ✦)
كل حاجة بتتغيّر بكثرة موجودة في ملف واحد بس: `data/config.json`
(ده ملف بيانات بيتقرا مباشرة من السيرفر في كل زيارة من غير أي تخزين مؤقت (cache)،
يعني أي تعديل فيه — زي رقم واتساب أو رابط سوشيال ميديا — بيوصل لكل الزوار فورًا)

```json
{
  "siteName": "Tota",
  "whatsapp": "201001234567",
  "whatsappMessage": "...",
  "socials": {
    "whatsapp":  "https://wa.me/201001234567",
    "telegram":  "",
    "facebook":  "",
    "instagram": "",
    "tiktok":    "",
    "email":     "info@example.com"
  },
  "featuredProducts": []
}
```

- أي وسيلة تواصل تسيبها فاضية `""` هتظهر تلقائيًا بشكل باهت مكتوب عليه **"قريبًا"** بدل ما تختفي، وباقي الوسائل المتاحة هتفضل شغالة عادي جدًا.
- اسم المتجر في `siteName` بيتحدّث تلقائيًا في الشعار، الـ tab title، والفوتر — مفيش داعي تدور في ملفات الـ HTML.
- الألوان والخط: متغيرات CSS في أول `assets/css/style.css` تحت `:root` (`--accent`, `--paper`, `--ink`...) ونسخة تانية لوضع الدارك تحت `[data-theme="dark"]`.

## إضافة منتج جديد
عشان تضيف منتج جديد مش محتاج تلمس أي كود HTML أو JS، بس اتبع الخطوات دي:

1. لو التصنيف (الكاتيجوري) مش موجود أصلاً، اعمل فولدر جديد جوه `products/` باسم التصنيف بالإنجليزي (زي `home-decor`)، وحط فيه ملف `category.json`:
   ```json
   { "name": "ديكور المنزل", "order": 3 }
   ```
2. جوه فولدر التصنيف، اعمل فولدر جديد باسم المنتج (بالإنجليزي وبدون مسافات، زي `wooden-lamp`)، وحط فيه:
   - `data.json` بالشكل ده:
     ```json
     {
       "name": "لمبة خشب يدوي",
       "price": 450,
       "oldPrice": 600,
       "currency": "EGP",
       "badge": "جديد",
       "description": "وصف قصير وجذاب عن المنتج.",
       "specs": [
         { "label": "الخامة", "value": "خشب زان طبيعي" },
         { "label": "الارتفاع", "value": "35 سم" }
       ]
     }
     ```
   - صورة المنتج باسم `main` وأي امتداد (`main.jpg`, `main.png`, `main.webp`, `main.svg`).
3. شغّل أمر البناء عشان يجمع كل المنتجات في ملف واحد يقرأه الموقع:
   ```bash
   npm run build
   ```
   (أو `npm run dev` لو عايز يبني تلقائي مع كل تعديل وانت شغال).

الملفات اللي بتتحدث فعليًا: فولدر `products/<category>/<product>/` (بتضيفه إنت)، وملف `data/products.json` (بيتبني لوحده بالأمر أعلاه). مفيش أي حاجة تانية محتاجة تتعدل.
